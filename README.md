> Secure, real-time clipboard synchronization and file sharing between devices using Peer-to-Peer technology.

ClipSync is a privacy-focused application that enables instant clipboard synchronization and file sharing between devices. Using WebRTC and end-to-end encryption, data is transferred directly between connected devices without relying on cloud storage or requiring user accounts.

---

## ✨ Features

### 🔄 Real-Time Clipboard Sync

Instantly synchronize copied text, links, and notes across connected devices.

### 📁 Direct File Transfer

Transfer files securely and directly without uploading them to third-party servers.

### 🔐 End-to-End Encryption

All communications are protected using modern cryptographic standards, ensuring only connected devices can access shared data.

### 🌐 Peer-to-Peer Connection

Powered by WebRTC DataChannels for fast and efficient device-to-device communication.

### 📱 Progressive Web App (PWA)

Install ClipSync on desktop and mobile devices for a native app-like experience.

### 🚫 No Account Required

No registration, login, or personal information needed. Simply join a room and start sharing.

---

## 🛡️ Privacy First

ClipSync is built around a privacy-first philosophy:

- No user accounts
- No cloud storage
- No server-side data retention
- Temporary session-based rooms
- End-to-end encrypted communication

Your data stays between the devices you connect.
